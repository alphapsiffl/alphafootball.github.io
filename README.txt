GITHUB PAGES:
1. Go to https://github.com/ and sign in.
2. Create a PUBLIC repository named YOURUSERNAME.github.io.
3. Upload all files in this folder to the root of the repository.
4. Open Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose the main branch and / (root), then Save.
7. Visit https://YOURUSERNAME.github.io/

MEDIA:
In script.js, replace the "Add photo/video link" placeholder with your actual hosted URLs when you have them. The site is intentionally set up so you can add YouTube, Google Drive, image, or other hosted links later.

ESPN:
The Stats and Schedule pages are placeholders for the ESPN data you provide. Once you send/export more ESPN data, those sections can be populated without changing the overall site design.
